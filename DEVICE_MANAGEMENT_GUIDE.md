# Device Management Guide

This guide explains how to use the Device Management page to add, edit, and delete devices.

## Accessing the Device Management Page

1.  Open the web application in your browser.
2.  Select the "Technical Profile" from the welcome screen.
3.  Click on the "Device Management" tab in the navigation bar.

## The Device Management UI

The Device Management page displays a table of all the devices in the system. Each row in the table represents a device and shows the following information:

*   **Device ID:** The unique identifier for the device.
*   **Model:** The model of the device.
*   **Friendly Name:** A user-friendly name for the device.
*   **Location:** The location of the device.

## Adding a New Device

1.  Click on the "Add Device" button to open the "Add Device" modal.
2.  Fill in the following fields:
    *   **Device ID:** A unique identifier for the device.
    *   **Device Model:** The model of the device.
    *   **Friendly Name:** A user-friendly name for the device.
    *   **Location:** The location of the device.
    *   **Shelly ID:** The ID of the Shelly device, if applicable.
    *   **API IP:** The IP address of the device's API, if applicable.
    *   **API Key:** The API key for the device, if applicable.
    *   **Notes:** Any additional notes about the device.
3.  Click on the "Save changes" button to add the new device.

## Editing an Existing Device

1.  Click on the "Edit" button (the pencil icon) next to the device you want to edit.
2.  The "Edit Device" modal will open with the device's current information.
3.  Modify the fields you want to change.
4.  Click on the "Save changes" button to update the device.

## Deleting a Device

1.  Click on the "Delete" button (the trash icon) next to the device you want to delete.
2.  A confirmation dialog will appear.
3.  Click on "OK" to confirm that you want to delete the device.
